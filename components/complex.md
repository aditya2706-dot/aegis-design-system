# Complex Components & Interaction Patterns

## Molecular & Organism Elements
* **Navigation Menus:** Top app bar, side drawer (collapsible), breadcrumbs. (Behavior: Sticky positioning, mobile hamburger toggle).
* **Modals/Dialogs:** Confirmation dialogs, full-screen forms. (Behavior: Trap keyboard focus, overlay backdrop, explicit close actions).
* **Data Displays:** * Accordions (Expandable content sections).
    * Tabs (Horizontal content switching).
    * Carousels (Swipeable/clickable media galleries).
    * Data Tables (Sortable headers, pagination, row selection, sticky columns).
* **Form Layouts:** Standardized single-column and multi-column responsive grid forms with step-by-step wizards.

## State & Error Handling
* **Empty States:** Friendly illustrations and clear Call-to-Actions (CTAs) when no data is present.
* **Loading States:** Skeleton loaders for content blocks; inline spinners for button actions.
* **Error Handling:** Inline validation messages beneath inputs, toast notifications for system-level errors.
